# Sachin Rawat — Engineering Portfolio

A modern, high-performance developer portfolio built with **React 18**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**. Engineered with a focus on fluid 60fps animations, accessible interactions, and responsive design.

---

## ⚡ Tech Stack

- **Core**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS + Custom CSS Variables + Glassmorphic Design System
- **Animation & Motion**: Framer Motion (Bento grid transitions, spring modals, physics-based effects)
- **Smooth Scrolling**: Lenis Scroll Engine
- **Icons**: Lucide React + Official Devicon Vector Icons
- **Deployment**: Vercel

---

## 🛠️ Key Engineering Features

- **Physics-Driven 3D ID Badge**: Interactive card physics with drag, velocity damping, and realistic string tension.
- **Hardware-Accelerated Bento Showcase**: Responsive 12-column grid showcasing real-world system architectures with tech stack deep-dives.
- **Dynamic Aurora Gradients**: Multi-stop animated text gradients adapted for seamless contrast across theme modes.
- **Client-Side Validated Contact Pipeline**: Asynchronous form handler with regex sanitation and instant feedback states.
- **Performance Optimized**: Sub-second initial load, zero render-blocking scripts, and static asset preloading.

## 🚀 Getting Started

### Prerequisites

Ensure you have **Node.js 18+** and **npm** installed.

### Installation

```bash
# Clone the repository
git clone https://github.com/<your-username>/portfolio-website.git

# Navigate to project directory
cd portfolio-website

# Install dependencies
npm install
```

### Development Server

```bash
npm run dev
```

Runs the application locally at `http://localhost:3000`.

### Production Build

```bash
npm run build
```

Compiles optimized production assets to the `dist/` directory.
